# Project Trinity
Project Trinity is a fast, modern web proxy powered by **Scramjet**, built for speed, privacy, and a clean UI.

## Features

- ⚡ Full Scramjet engine (bare-mux, epoxy, wisp client, service worker)
- 🧭 Custom **Project Trinity** homepage
- 🔍 Working search that routes URLs through `/scramjet/`
- 🕶️ Tab cloaking / about:blank–style support
- 📱 Responsive layout for desktop and mobile
- 🔒 No Google sign-in or external auth required
- 📂 Keeps all core Scramjet internals intact
